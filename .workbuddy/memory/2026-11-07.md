## 修复 home/ 春节主题（spring.js / spring.css）

用户反馈春节主题"没用"。诊断与修复：

- **日期写错（根因）**：`new Date(2026, 11, 1)` 因月份 0 基实为 2026-12-01（注释却写 2/3）；`new Date(2027, 1, 13)` 是 2027-02-13，而 2027 春节 2/6、元宵 2/20，仍在正月初八。当前 11/7 尚未触发。
  → 改为 `PERIODS` 配置数组 + `"YYYY-MM-DD"` 字符串 + 本地时间解析（避免 ISO 被当 UTC），半开区间 `[start, end)`；2027 档期定为 2027-01-30 ~ 2027-02-22（不含）。以后每年加一行即可。
- **CSS 看不见效果**：`styles.css` 的 `.cyber-title` / `.data-number` 用 `background-clip:text` + `color:transparent`，旧 spring.css 只改 `color` 无效 → 改 `background-image` 为金红渐变并设 `-webkit-text-fill-color`。
- **配色冲突**：旧版未覆盖 `--secondary-color`（品红），大量 primary→secondary 渐变不协调 → 覆盖为金色 `#ffd54f`；同时改掉未被引用的 `--bg-color`，改用真正生效的 `--dark-bg` / `--darker-bg`。
- **副标题不联动**：旧版判断在 IIFE 外只执行一次，每小时 `checkSpringTheme` 不会更新文案，切回 normal 也不还原 → 合并进 `applyTheme()`，用 `dataset.springOriginal` 保存原文。
- 新增 `?spring=1` / `?spring=0` 强制开关便于随时预览；新增 `visibilitychange` 即时校准、`DOMContentLoaded` 保护、`prefers-reduced-motion` 支持；删除无人使用的 `document.body.dataset.spring`。

验证：`node --check` 通过；用 Node `vm` mock DOM 跑 11 组日期/参数用例全部符合预期，并验证跨档期边界后文案能还原。
